# Báo Cáo PDF Đồ Án Môn Học (PDF Deliverables)

Thư mục này dùng để lưu trữ các file báo cáo PDF nộp cho Giảng viên:
- `[groupname]-report.pdf`: Báo cáo PDF toàn văn tổng hợp cả 3 bài toán.
- `[groupname]-tabular-report.pdf`: Báo cáo chi tiết phân mục Dữ liệu Dạng Bảng.
- `[groupname]-text-report.pdf`: Báo cáo chi tiết phân mục Dữ liệu Văn bản (NLP).
- `[groupname]-image-report.pdf`: Báo cáo chi tiết phân mục Dữ liệu Hình ảnh (Vision).

Hãy copy các file PDF của nhóm vào đây và đảm bảo tên tệp khớp với đường dẫn khai báo trong các tệp HTML.
